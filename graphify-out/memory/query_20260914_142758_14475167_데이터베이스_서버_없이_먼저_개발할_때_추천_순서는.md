# Q: 데이터베이스 서버 없이 먼저 개발할 때 추천 순서는?

## Answer

Expanded from original query via graph vocab: graphql, authentication, otp, sms, user, store, menu, order, contract, validation, memory, database. 먼저 민감정보 로깅 제거와 OTP 난수 보강을 한다. 다음으로 GraphQL 인증 계약을 만들고 AuthService 내부 Map을 사용한 process-local 개발용 인증 수직 슬라이스를 구현한다. 이어서 정적 fixture 기반 매장 및 메뉴 조회, 순수 주문 규칙과 인메모리 주문 저장, 핵심 사용자 흐름 e2e 테스트를 만든다. DB가 준비되면 그때 MikroORM을 설치하고 Map과 fixture 저장만 엔티티 및 쿼리로 교체한다. 미리 범용 repository나 UnitOfWork 추상화는 만들지 않는다.
