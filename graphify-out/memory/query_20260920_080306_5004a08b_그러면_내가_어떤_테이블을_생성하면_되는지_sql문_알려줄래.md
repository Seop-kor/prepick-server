# Q: 그러면 내가 어떤 테이블을 생성하면 되는지 sql문 알려줄래?

## Answer

Expanded from original query via graph vocab: [users, otp, challenge, refresh, session, phone, verification, token, schema, constraints]. The auth contract requires public.users, public.otp_challenge, and public.refresh_session. Required uniqueness is users.phone, otp_challenge.verification_token, and refresh_session.user_id; refresh_session.user_id references users.id with ON DELETE CASCADE. CamelCase entity properties map to snake_case columns, Date maps to timestamptz, and application-generated UUIDs need no database extension.
